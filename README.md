# ОРВИ 2027 — Калькулятор

Веб-приложение для оценки вероятности заболеть ОРВИ в 2027 году
на основе байесовской модели с сезонностью Москвы и персональными факторами.

## Демо

https://qscorpi.github.io/orvi/

## Модель

- Априорное распределение числа эпизодов: отрицательное биномиальное
  (эквивалент Gamma-Poisson).
- Сезонные веса по месяцам на основе статистики ОРВИ в Москве.
- 95% доверительный интервал через квантили Gamma-распределения.

## Стек

- HTML + JavaScript
- Plotly.js (графики)
- GitHub Pages (хостинг)

## Локальный запуск

1. Клонировать репозиторий.
2. Открыть `index.html` в браузере
   или использовать расширение **Live Server** в VS Code.
