# ОРВИ 2027 — Калькулятор вероятности заболеть

Веб-приложение для оценки **персональной вероятности заболеть ОРВИ** в течение 2027 года.
Учитывает сезонность, демографию, образ жизни, историю болезни и структуру циркулирующих вирусов.

**[→ Открыть калькулятор](https://qscorpi.github.io/orvi/)**

---

## Зачем это нужно

Большинство людей примерно представляют, что «зимой болеют чаще». Но на конкретный вопрос
«сколько раз я лично заболею в следующем году» ответить интуитивно сложно: слишком много
факторов — возраст, работа, транспорт, дети, сон, стресс, прививки, история прошлых лет.

Этот калькулятор даёт **количественную оценку**: не «часто» или «редко», а вероятности —
«13% что не заболеешь ни разу, 27% что заболеешь один раз, 27% что два» и так далее.
Плюс показывает, **когда именно** риск максимален и **какие вирусы** его формируют.

Инструмент не заменяет врача. Это модель для самообразования и планирования.

---

## Как пользоваться

1. Откройте **[калькулятор](https://qscorpi.github.io/orvi/)**.
2. Заполните поля в левой панели — они описывают ваш профиль и образ жизни.
3. В блоке «Сколько раз вы болели за последние годы» укажите вашу реальную статистику.
   Чем больше лет — тем точнее персональная оценка. Если не помните — оставьте значения по умолчанию.
4. Смотрите графики справа:
   - **Верхний график** — распределение числа эпизодов за год.
     Переключатель «Ровно k раз» / «Хотя бы k раз» меняет форму представления.
   - **Нижний график** — сезонность. Переключатель «Сумма» / «По вирусам» показывает
     либо общую кривую риска по дням, либо разбивку по типам вирусов.

## На основании каких данных сделана модель

Модель объединяет **три источника**:

### 1. Популяционная статистика ОРВИ

Средняя частота у взрослых — **2–4 эпизода в год** (клинические рекомендации по ОРВИ,
обзоры по инфекциям верхних дыхательных путей). У детей — **6–10 раз в год**.
Базовая интенсивность в модели — **λ = 2.0 эпизода в год** для «среднего взрослого».

### 2. Эпидемиологические коэффициенты влияния факторов

Каждый фактор (возраст, транспорт, дети в доме, курение, сон, стресс, прививка)
умножает базовую λ на свой коэффициент. Значения взяты из обобщённых эпидемиологических
обзоров и округлены до «инженерной» точности. Коэффициенты **не претендуют на
медицинскую точность** — они отражают направление и примерную величину эффекта.

### 3. Сезонные профили вирусов

ОРВИ — это не одна болезнь, а **десятки разных вирусов**, у каждого своя сезонность.
В модели учитываются:

| Вирус                          | Доля в общей λ | Пик сезона         |
| ------------------------------ | -------------- | ------------------ |
| Риновирус                      | 35%            | сентябрь–октябрь   |
| Грипп                          | 25%            | декабрь–февраль    |
| Коронавирус (сезонный)         | 20%            | декабрь–февраль    |
| RSV                            | 10%            | январь–март        |
| Другие (аденовирус, парагрипп) | 10%            | распределены ровно |

Сумма сезонных профилей этих вирусов даёт **общую сезонную кривую** ОРВИ.
Это принципиальный момент: в модели **нет отдельного «графика сезонности»** —
он автоматически складывается из вкладов отдельных вирусов.

> ⚠️ **Важно:** источники весов и коэффициентов — обобщённые, а не точные данные
> по конкретному региону и году. Модель калибрована на разумные средние, а не
> на официальную статистику Роспотребнадзора. Это осознанный компромисс между
> сложностью и прозрачностью.

## Математика: как считается вероятность

### Шаг 1. Персональная интенсивность λ

Начинаем с **байесовской оценки** вашей личной интенсивности:

λ_personal = (w · λ_prior + Σ history_i) / (w + N)

- `λ_prior = 2.0` — популяционное среднее.
- `w = 2.0` — «вес» приора в годах. Защищает от выбросов.
- `history_i` — сколько раз вы болели в каждый прошлый год.
- `N` — сколько лет истории вы ввели.

**Пример:** история [2, 3, 2] → `λ = (2·2 + 7) / (2+3) = 2.2`.
То есть модель сдвигает оценку в сторону вашей истории, но не доверяет ей полностью.

К этой базе применяются **множители факторов**:
λ = λ_personal
× f_age × f_sex × f_region × f_work
× f_transport × f_kids × f_chronic
× f_vaccine × f_smoke × f_sleep × f_stress

Каждый множитель ≥ или ≤ 1.0. Итоговая λ — ожидаемое число эпизодов за год.

### Шаг 2. Распределение числа эпизодов

Используется **отрицательное биномиальное распределение** (NegBinom). Оно возникает
естественным образом, если считать, что у каждого человека своя λ, а она сама
распределена по Gamma-закону:
N | λ ~ Poisson(λ)
λ ~ Gamma(α, β)
⇒ N ~ NegBinom(α, p)

Параметры:

- `CV = 0.5` — коэффициент вариации Gamma-приора. Чем больше CV, тем «тяжелее хвост».
- `α = 1 / CV²`, `β = α / λ`, `p = β / (β+1)`.

Вероятность «ровно k эпизодов»:
P(N=k) = C(α+k-1, k) · p^α · (1-p)^k

Вероятность «хотя бы k эпизодов»:
P(N≥k) = 1 − P(N≤k−1)

**Почему не простой Пуассон?** Потому что население неоднородно: есть люди,
которые почти не болеют, и есть «часто болеющие». NegBinom это учитывает — он даёт
более тяжёлый хвост, ближе к реальным данным.

### Шаг 3. Сезонность по дням

Каждый вирус имеет **месячный вес** и **долю в общей λ**. Для дня `d` в месяце `m`:
риск*вируса*в*день_d = (доля*вируса × месячный*вес*вируса[m] / дней*в*месяце) × λ общий*риск*в*день_d = Σ*вирусы риск*вируса*в_день_d

Сумма по всем 365 дням = λ. То есть мы «размазываем» годовую интенсивность по дням
с учётом сезонных профилей вирусов.

### Шаг 4. Иммунный долг (готово, но пока не подключено в UI)

После перенесённого эпизода риск на **42 дня** падает до **30%** от обычного
(гомологичный иммунитет). Функция `immuneFactor(events)` реализована в модели,
но пока не подключена к интерфейсу — это следующий шаг развития.

### Шаг 5. Доверительный интервал

95% интервал строится через **квантили Gamma-распределения** (приближение Wilson–Hilferty).
На графиках он показан пунктирными линиями: нижняя 2.5%, верхняя 97.5%.

## Стек

- **HTML + CSS + vanilla JavaScript** — никаких фреймворков.
- **ES-модули** (`<script type="module">`) — нативный импорт между файлами.
- **[Plotly.js](https://plotly.com/javascript/)** — графики.
- **GitHub Pages** — хостинг, разворачивается автоматически из `main`.

Проект **не требует сборки**: открывается в браузере напрямую. Live Server в VS Code —
для локальной разработки.

## Ограничения и оговорки

- **Это не медицинский инструмент.** Модель даёт вероятностную оценку, а не диагноз
  или предписание. Для реальных решений о здоровье — обращайтесь к врачу.
- **Коэффициенты факторов — обобщённые.** Они показывают направление и примерную
  величину эффекта, но не откалиброваны на конкретную популяцию.
- **Сезонные веса вирусов — иллюстративные.** Они согласованы с эпидемиологическими
  представлениями, но не являются точными данными за 2027 год.
- **Иммунный долг пока не подключён к интерфейсу.** В модели есть функция, но UI
  её не использует — это следующий шаг.

Все эти ограничения — часть **учебного проекта**. Цель не в медицинской точности,
а в демонстрации того, как строится количественная вероятностная модель: от данных
через математику к визуализации.

## Учебный проект

Это **учебный проект**, созданный для изучения:

- модульной архитектуры на vanilla JS без фреймворков;
- байесовского подхода к персональным оценкам;
- эпидемиологического моделирования (сезонность, распределения, иммунитет);
- работы с Plotly.js для научной визуализации;
- Git-процесса: ветки, Pull Requests, code review.

Проект **не претендует** на научную новизну или медицинскую точность. Он показывает,
как инженер-программист подходит к задаче моделирования: разбивает на слои, выносит
константы, пишет чистые функции, добавляет фичи по одной через отдельные ветки.

Если вы учитесь — форкайте, разбирайте код, экспериментируйте. Если вы медик или
эпидемиолог и видите неточности — открывайте issue, это полезно.
